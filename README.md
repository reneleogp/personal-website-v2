## Stack

- Gatsby 3
- React 17
- styled-components
- Netlify

## Development

Use the Node version in `.nvmrc` and install dependencies with Yarn.

```sh
nvm install
nvm use
yarn install --frozen-lockfile
yarn develop
```

The development site runs at `http://localhost:8000`.

## Production

Build and preview the static site locally:

```sh
yarn build
yarn serve
```
